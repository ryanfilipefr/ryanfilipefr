## Hola, soy Ryan

**Arquitecto de Sistemas | Ingeniero Full-Stack | IA y Automatización**

Diseño y desarrollo sistemas de software, desde la arquitectura y las decisiones técnicas hasta el desarrollo, la integración y el despliegue.

Mi trabajo abarca la ingeniería full-stack, las aplicaciones de inteligencia artificial y la automatización. Valoro los sistemas que pueden crecer sin volverse difíciles de mantener, ofrecen visibilidad útil sobre su funcionamiento y se recuperan de forma segura cuando algo falla.

## Qué desarrollo

- Arquitecturas de sistemas capaces de evolucionar con el tiempo.
- Productos full-stack con contratos claros entre la interfaz, el backend y las capas de datos.
- Aplicaciones de IA que separan las sugerencias del modelo de la ejecución confiable.
- Automatizaciones operativas con idempotencia, intervención humana y recuperación ante fallos.
- Aplicaciones móviles y herramientas para desarrolladores con una distinción clara entre el comportamiento de demostración y el de producción.

## Proyectos destacados

### Meu Estagiário

Una plataforma operativa que conecta una interfaz en React, un núcleo basado en Supabase, un entorno de ejecución Windows e integraciones autorizadas con navegadores.

### VULK4N

Una plataforma local de investigación de seguridad para análisis HTTP con alcance definido, pruebas en un laboratorio autorizado e informes auditables.

### Oracle / Context Engine

Una arquitectura de memoria y contexto que explora la resolución de entidades, la recuperación semántica, la atención y la fiabilidad de la información almacenada.

### Vibz Mobile

Una aplicación en React Native y Expo con flujos de demostración aislados, contratos de API tipados y una arquitectura orientada a dispositivos móviles.

### Assistente Lavae

Un sistema basado en Cloudflare Workers que utiliza D1, colas, enrutamiento conservador mediante IA y transferencia explícita a una persona.

## Tecnologías

- **Lenguajes:** TypeScript, JavaScript, Python, Dart y SQL
- **Frontend y móvil:** React, Vite, React Native, Expo y Flutter
- **Backend y datos:** Node.js, Cloudflare Workers, Supabase, PostgreSQL, SQLite y D1
- **Ingeniería:** GitHub Actions, pruebas automatizadas, diseño de APIs, extensiones de navegador y automatización en Windows

## Cómo trabajo

Prefiero los cambios pequeños y verificables, los límites de confianza claros, la documentación que refleja la implementación y las automatizaciones que fallan de forma segura.

Una buena arquitectura responde a las necesidades actuales y deja margen para los cambios sin añadir complejidad innecesaria. Conecto las decisiones arquitectónicas con la implementación práctica para crear software que las personas puedan comprender, operar y mantener.
