# RF. Identity Guide

## Positioning

**Ryan Filipe**  
Software Engineer | Full-Stack | AI & Automation

The identity should communicate precision, modern engineering and quiet confidence. It avoids decorative statistics, excessive badges and visual noise.

## Mark

`RF.` is the primary monogram. The period is the only color accent and represents completion, intent and an engineering checkpoint.

Use the square mark for avatars, favicons and compact signatures. Use the horizontal header only where it improves orientation, such as the GitHub profile or a portfolio landing page.

## Color tokens

| Token | Value | Use |
|---|---|---|
| Ink | `#111318` | Primary dark surface and text on light backgrounds |
| Paper | `#F5F7FA` | Primary light surface and text on dark backgrounds |
| Muted | `#AAB1BE` | Secondary text |
| Accent | `#6C8CFF` | Period, focus and restrained highlights only |

The SVG assets use a dark neutral surface so they remain legible in GitHub light and dark modes.

## Typography

Preferred UI stack: `Inter, Segoe UI, Arial, sans-serif`. Inter is optional; the assets and layouts must remain balanced with system fallbacks.

## Rules

- Keep generous negative space.
- Use one accent color only.
- Avoid gradients, glow, neon and large badge collections.
- Prefer evidence and concise technical writing to decorative metrics.
- Never stretch the monogram or separate the period from `RF`.
- Do not place the mark over busy imagery.
